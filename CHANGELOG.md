# Changelog

## 0.1.8 — First Public Release

Released to Google Play Production in September 2026.

### Highlights

- First public Android release of With Alia.
- One continuing Alia identity rather than interchangeable characters.
- Long-term conversational memory and cross-session continuity.
- Improved recall of important relationship details shared by the user.
- Better handling of recent references such as “I already told you.”
- Alia self-context and developing preferences are kept separate from user memory.
- Russian and English support.
- Reliability improvements for startup, cold restart, and background/resume.

### Product direction

This release marks the transition from closed testing to real-world public usage. Future updates will prioritize issues observed in production, user feedback, monetization, design refinement, and later iOS support.

### Notes

The production application code remains private while active development continues. This public repository documents the product direction, human-centered AI principles, evaluation ideas, and release milestones.
